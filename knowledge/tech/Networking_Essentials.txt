1. INTRODUCTION TO ISOLATED LOCAL NETWORKS (LAN)
Setting up a Local Area Network (LAN) that does not connect to the internet is
critical for secure off-grid data retrieval, local chat systems, file sharing,
and access to offline web applications such as NuclearUSB.

2. CONFIGURING A BASIC OFFLINE ROUTER
To establish a LAN:
- Connect devices to a router or switch using Category 5e/6 Ethernet cables or
  local Wi-Fi.
- Log into the router management console, commonly 192.168.1.1 or 192.168.0.1.
- Enable DHCP to automatically hand out internal IP addresses to clients.
- For static configurations, disable DHCP and assign IPs manually:
  - Device A: IP 192.168.1.10, Subnet Mask 255.255.255.0
  - Device B: IP 192.168.1.11, Subnet Mask 255.255.255.0
  - Test connection with ping, for example: ping 192.168.1.10

3. OFFLINE DNS RESOLUTION
Without internet, public DNS servers such as 8.8.8.8 will not work.
- Set up a local DNS service on a central server node.
- Configure client devices to point to this node's IP for DNS resolution.
- Alternatively, edit the hosts file on each client:
  - Windows: C:\Windows\System32\drivers\etc\hosts
  - Add line: 192.168.1.10 nuclearusb.local

4. TCP HANDSHAKE BASICS
TCP connections begin with a three-step handshake: SYN, SYN-ACK, and ACK.
The client sends SYN to request a session. The server replies with SYN-ACK to
acknowledge the request and offer its own sequence number. The client then sends
ACK to confirm the connection. If any step fails on an isolated LAN, check IP
addressing, firewall rules, listening ports, and whether both hosts can reach
each other with ping or local routing diagnostics.

5. SOLAR POWER AND OFF-GRID CHARGING
When running network nodes or laptops off-grid:
- Calculate total daily Watt-hours (Wh) consumption.
- A laptop at 45W for 4 hours uses 180Wh.
- A router at 10W for 24 hours uses 240Wh.
- A 100W solar panel yields about 400-500Wh per day under optimal sun.
- Use LiFePO4 batteries for energy storage because they offer high cycle life
  and lower weight compared to lead-acid batteries.
- Do not charge lithium batteries below freezing temperatures to avoid
  permanent battery damage.
