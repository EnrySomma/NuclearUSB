1. EXCEPTION HANDLING
Python handles errors with `try`, `except`, `else`, and `finally` blocks.
- Always catch specific exceptions rather than using a bare `except:`.
- Example:
  ```python
  try:
      with open("data.txt", "r") as file:
          content = file.read()
          value = int(content)
  except FileNotFoundError as e:
      print(f"Error: File was not found: {e}")
  except ValueError:
      print("Error: Could not convert file content to integer.")
  else:
      print("Operation completed successfully without errors.")
  finally:
      print("Execution finished (runs always).")
  ```

2. SQL AND DATABASE QUERIES
Python integrates with SQL databases like SQLite natively.
- Example:
  ```python
  import sqlite3
  
  conn = sqlite3.connect("database.db")
  cursor = conn.cursor()
  
  # Parameterized query to prevent SQL Injection
  user_id = 42
  cursor.execute("SELECT name, email FROM users WHERE id = ?", (user_id,))
  row = cursor.fetchone()
  if row:
      print(f"User Name: {row[0]}, Email: {row[1]}")
      
  conn.close()
  ```

3. FILE I/O
Using context managers (`with`) ensures file handlers are closed automatically.
- Read file:
  ```python
  with open("file.txt", "r", encoding="utf-8") as f:
      lines = f.readlines()
  ```
- Write file:
  ```python
  with open("output.txt", "w", encoding="utf-8") as f:
      f.write("Line content\n")
  ```
