# NuclearUSB UI Assets

This folder contains local, offline-safe visual assets used by the static UI.

- `nuclearusb-logo.png`: horizontal brand logo for the header.
- `nuclearusb-mark.png`: compact mark for app icon and welcome panels.
- `favicon.png`: browser favicon.
- `placeholder-card.svg`: generic data/card placeholder.
- `placeholder-source.svg`: source/citation empty-state placeholder.
- `placeholder-guide.svg`: medical guide/document empty-state placeholder.

The placeholder SVGs are intentionally lightweight. Replace them later with real artwork only if the UI needs richer visual previews; keep replacements local so the Windows offline build does not depend on external URLs.
